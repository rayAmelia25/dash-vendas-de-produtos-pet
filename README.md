## 📌 Sobre o Projeto

Este projeto consiste em um dashboard interativo desenvolvido para análise de vendas e gestão de estoque no segmento pet. O objetivo é transformar dados em informações estratégicas que auxiliem na tomada de decisões, permitindo identificar padrões de consumo, oportunidades de crescimento e possíveis gargalos operacionais.

## 📈 Principais Insights Obtidos

### 🧸 Desbalanceamento entre Estoque e Vendas

A análise revelou que a categoria **Acessórios** concentra a maior parte do estoque disponível, enquanto **Brinquedos** apresenta o maior volume de vendas. Esse comportamento sugere um desalinhamento entre oferta e demanda, indicando oportunidades para otimizar a alocação de estoque e reduzir capital parado.

### 🐱 Potencial de Crescimento no Público Felino

Apesar da operação estar fortemente direcionada ao público canino, os dados mostram participação significativa dos tutores de gatos na compra de brinquedos. Isso evidencia uma oportunidade de expansão e diversificação do portfólio voltado para esse segmento.

### 🍖 Oportunidade na Categoria Alimentação

A categoria de alimentação apresenta baixa participação no estoque total. Considerando o caráter recorrente desse tipo de compra, existe potencial para estratégias de fidelização, programas de assinatura e aumento do ticket recorrente.

### 📊 Correlação entre Interesse e Vendas

Foi observada uma relação positiva entre o interesse dos usuários e o volume de vendas dos produtos. Esse comportamento demonstra o potencial de utilização dos dados de navegação para construção de modelos preditivos de demanda.

### ⭐ Impacto das Avaliações dos Produtos

Produtos com melhores avaliações tendem a apresentar maior volume de vendas. A análise reforça a importância da experiência do cliente e abre espaço para futuras análises de sentimento em avaliações textuais.
